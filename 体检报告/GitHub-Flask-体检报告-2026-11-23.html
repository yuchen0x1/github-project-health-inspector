P1 高优先级问题 无 P0；以下三项互为因果

P1-1 运行时依赖 werkzeug 锁定版本存在已知漏洞

位置
uv.lock · werkzeug 3.1.8（修复于 3.1.9）
依据
GHSA-g6x2-hccm-hh4m · safe_join() 允许 Windows 特殊设备名 · MODERATE
影响
本项目 CI 与贡献者环境；下游用户因 werkzeug>=3.1.0 范围声明通常已获修复版，不直接受影响
修复
uv lock --upgrade-package werkzeug && uv sync，并把下限提到 3.1.9

P1-2 缺少依赖自动更新机制，导致漏洞持续累积

新增 dependabot（uv weekly + 分组 + patch 自动合并）
